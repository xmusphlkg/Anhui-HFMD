# Anhui-HFMD

This repository contains analysis code, figures, supplementary appendix source, and aggregated analytic outputs for the manuscript:

**Hand, Foot, and Mouth Disease Surveillance in Anhui, China After Enterovirus 71 Vaccine Introduction and During COVID-19: Ecological Interrupted Time-Series Study**

## Data Availability

The individual-level hand, foot, and mouth disease surveillance records used in this study are not included in this public repository because they are statutory notifiable infectious disease surveillance data governed by the Anhui Provincial Center for Disease Control and Prevention.

Publicly shared files in this repository are limited to:

- analysis scripts;
- generated figures;
- supplementary appendix source;
- aggregated supplementary tables and aggregated Excel outputs.

Requests for access to individual-level surveillance records require approval from the data custodian. The aggregated outputs provided here are intended to support interpretation of the manuscript without exposing record-level surveillance data.

## Notes on Reproducibility

Some scripts reference private source-data files that are intentionally excluded from the public repository. These scripts document the analytic workflow, while the public `outcome/` directory provides aggregated outputs generated from the approved surveillance extract.
