Supplementary Data D9 includes the following CSV files:

- `supplementary_data_D9_annual_age_composition.csv`: annual age composition of reported HFMD cases from 2008 to 2023.
- `supplementary_data_D9_period_summary.csv`: aggregated age composition for 2017-2019 versus 2021-2023.
- `supplementary_data_D9_statistics.csv`: chi-square comparison and odds ratio for the 4+-year age group in 2021-2023 versus 2017-2019.
